# EDA(Exploratory data analysis)
This repository contains a collection of Exploratory Data Analysis (EDA) basics,covering real-world datasets. The projects include data cleaning, merging, transformation, visualization, and feature engineering using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn. It also includes structured data analysis and statistical testing across multiple datasets.



### 1. data_prep_titanic
In this work, I performed data merging, cleaning, and exploratory analysis using Python and Pandas. I demonstrated different types of joins (inner, left, right, and outer) to combine datasets based on a common key. I then applied these concepts to the Titanic dataset by handling missing values, converting categorical variables, and creating new features such as family size. Additionally, I used crosstab analysis to explore relationships between variables like survival, gender, and passenger class. This project highlights key data preprocessing and analysis techniques used in data science.


### 2. data_prep_data_covid
In this work, I performed data cleaning and preprocessing on a COVID-19 clinical dataset using Python and Pandas. I handled missing values through different strategies such as mean imputation and group-based imputation, and removed outliers using statistical methods based on the interquartile range (IQR). I also corrected inconsistent data entries and converted variables into more suitable formats for analysis. Additionally, I created new features such as age groups to improve data interpretability and performed targeted imputations based on demographic characteristics like age and gender. Finally, the cleaned dataset was prepared and saved for further statistical analysis and modeling.


### 3. t_test
To have a review of different t-test analysis in Python, In this work, I implemented statistical hypothesis testing using Python and SciPy to compare sample means under different conditions. I simulated synthetic datasets using probability distributions and applied one-sample t-tests to compare a sample against a population mean. I also performed independent two-sample t-tests to evaluate differences between two unrelated groups and used a paired t-test to analyze before-and-after measurements on the same subjects. In addition, I computed confidence intervals to estimate the range of the true population mean and interpreted statistical significance using both p-values and critical t-values. This project demonstrates the application of inferential statistics for comparing groups and drawing data-driven conclusions.
